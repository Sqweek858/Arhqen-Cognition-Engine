# ACE-AQUI1 - Aquarium Telemetry Widgets

ACE-AQUI1 adds early visual telemetry widgets for the Aquarium runtime. The 3D environment now has a compact telemetry strip instead of hiding every useful signal in log text like a Victorian accountant.

Implemented:

- `D2DAquariumTelemetryWidgets`.
- Hydration, nutrition and integrity bars.
- Mini event timeline strip from current log volume/step.
- Telemetry render counters.
- Integration into the single-HWND composite 3D viewport.

Non-goals:

- No new cognition logic.
- No AQ-M16+.
- No new 3D visuals.

Next: add planner confidence, self-model drift, proto-concept growth and world hazard heat widgets.
